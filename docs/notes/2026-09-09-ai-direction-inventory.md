# AI direction inventory — Phase 1

Every instruction or mechanism in this repo that changes what a model does, one row each, grouped by where it lives. This is the raw material for the leverage ranking in Phase 2; nothing here is ranked.

## What was read

Both `CLAUDE.md` layers, `CLAUDE.local.md`, all five `.claude/rules/` files, all four hooks and `settings.json`, all 21 `SKILL.md` bodies with every reference, asset, and example under them, all 11 agents, the PR template, CI workflow, husky hook, `BRANDING.md`, the full `CHANGELOG.md`, the ADR, company overview, all five `docs/notes/`, all 14 `docs/tasks/`, the four setup scripts, two of the three test batteries, `.mcp.json`, `package.json`, `turbo.json`, prettier config, `.gitignore`, and the untracked `notes/DESIGN_PRINCIPLES.md`.

Not read: `scripts/test/check-install.battery.mjs`, `scripts/test/env-matrix/*.sh`, `LICENSE`, `.nvmrc`, `pnpm-workspace.yaml`. They are test fixtures and pins with no AI-facing instruction.

## How to read the table

- **Instruction**: quoted where the wording is load-bearing, closely paraphrased otherwise.
- **Lives in**: file path, section, and line numbers where the file was read with them.
- **Failure mode**: what the model does wrong when the instruction is absent. Where the repo's own history recorded the failure in an instance before the rule landed, the changelog or task entry is named.
- **Tooling**: `Pure` works in any chat. `Hook`, `Config`, `Skill`, `Subagent`, `LSP`, `CLI`, `File`, `MCP` name the dependency. `Pure + X` means the instruction stands alone and X is a backstop.

Two observations that belong here rather than in the ranking. The repo's own history is the failure-mode evidence: rows 13, 37, 40, 118, 120, 132, 178, and 190 each cite a changelog or task entry where the failure was observed and measured before the rule landed. And the repo states explicitly which rules have no enforcement behind them (rows 57, 165, 173: "No hook enforces this; the description and the rule are the whole mechanism"), which matters when deciding what survives a bare chat.
